
🚛 Sistema Transportadora


Sistema de gestão de transportadora desenvolvido em C# Console Application, aplicando conceitos de Programação Orientada a Objetos (POO), organização em camadas e tratamento de exceções. São duas versões a primeira versão(Sistema_Transportadora) e a segunda versão(sistemaTransportadora(Verão Original))


📌 Funcionalidades

✅ Gestão de veículos

✅ Gestão de motoristas

✅ Controle de viagens

✅ Gestão de rotas

✅ Controle de manutenção

✅ Validação de dados

✅ Tratamento de exceções personalizadas
